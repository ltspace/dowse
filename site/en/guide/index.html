Dowse desktop app · User guide

Search your local files with Dowse

This guide covers the Windows desktop app. There is no search-engine setup to learn: choose your folders, let the first index finish, then use the hotkey and type any part of a name or passage you remember.

Install and build the first index

  1. Install Dowse. Download the installer ending in setup.exe from GitHub Releases. The current installer is unsigned. If SmartScreen stops it, first confirm that the file came from the project release page, then choose “More info” and “Run anyway.”
  2. Open the search window. Dowse stays in the system tray after launch. Press Alt+` (the backtick key next to 1) to show it, or left-click its tray icon.
  3. Choose the first folder. On the empty screen, click “Choose a folder and build the index.” Start with a place you search often, such as Documents or a work folder. Dowse only searches folders you explicitly add.
  4. Let the text pass finish. The window shows the number of files processed and the current file. Text becomes searchable when that pass completes. If the folder contains images, OCR may continue in the background; a strip at the bottom shows its progress.

Start with a useful boundary. Add the folders that actually contain your material instead of indexing an entire system drive. The first pass will be quicker and the results less noisy. You can add more folders from the tray later.

Add more folders

Right-click the tray icon and choose “Indexed folders” → “Add folder…”. The new folder is added to the existing index; it does not replace earlier folders. The submenu shows the current document count beside each root.

Everyday search and result actions

Press Alt+` and start typing. A query can be part of a file name or words from a PDF, Office document, source file, or text file. Multiple words must all match by default. Put a remembered sentence in double quotes when word order matters.

The left side shows names, paths, and matching passages; the right side shows a preview. Drag the divider to give either side more room. Results are paged in groups of 50. Page controls appear only when needed, and pressing ↓ after the last row moves to the next page.

Filter and sort

The quiet controls at the right of the search box filter by all files, documents, code, or images. The neighboring menu sorts by relevance, newest, oldest, or largest. A non-default choice remains visible so that you can tell why the list changed.

Open, reveal, and copy

  • Double-click a result, or select it and press Enter, to open it in its default application.
  • Press Ctrl+Enter to reveal the file in File Explorer.
  • Press Ctrl+C to copy the full path.
  • Right-click a result to open it, reveal its folder, copy its path, or copy only its name.

The pin in the top-right keeps Dowse visible when focus moves to another application. Pinning lasts for the current run and resets after Dowse restarts.

Recent searches

Clear the search box to see the last ten queries. Select one with the arrow keys and press Enter to run it again, or press Delete to remove the selected entry. This history is stored only on your computer.

Search syntax

Plain words are enough for most searches. Add these forms to the same query when you need a narrower result set.

FormWhat it doesExample
SpacesRequire all terms (AND)quarterly budget
Double quotesMatch an exact phrase"release checklist"
path:Match a file name or folder path; quote paths containing spacesbudget path:reports
path:"My Docs"
ext:Limit results to one extensiondeployment ext:md
mtime:Filter by modification date with >, >=, <, or <=contract mtime:>=2026-01
size:Filter by size; B, KB, MB, and GB are acceptedlog size:>10mb
-term or NOT termExclude results containing a termproposal -deprecated
ORMatch either group; OR must be uppercasequotation OR budget

Dates may use YYYY-MM-DD or YYYY-MM. Conditions inside a group are combined before uppercase OR separates groups. For example: path:customers contract OR path:internal template.

Settings and index rules

Click the small gear in the top-right, press Ctrl+,, or choose “Settings…” from the tray menu.

General

  • Toggle shortcut: choose “Change,” press the new combination, then confirm it. The shortcut must contain Ctrl, Alt, Shift, or Win plus a main key. If another application already owns it, Dowse keeps the old shortcut.
  • Transparency: turn the effect off completely, or enable it and choose low, medium, or high opacity.
  • Launch at startup: decide whether Dowse starts when you sign in to Windows.
  • Language: follow the system language or select English or 中文. Restart Dowse after changing this setting.

Index rules

  • Excluded folders: enter folder names separated by commas or new lines. Defaults include node_modules, target, .git, .venv, and __pycache__. Dot-folders are always excluded.
  • Extra text extensions: add project-specific plain-text formats such as rst, adoc. These extend the built-in list rather than replacing it; omit the leading dot.
  • Maximum file size: the default is 20 MB. Larger files are skipped so that an unexpectedly large file cannot dominate an indexing run.

New file changes use saved rules, but rebuild the index to make existing entries fully consistent. With one indexed root, “Rebuild now” is available in the panel. With several roots, rebuild each one from the tray menu.

Maintain indexed folders

While Dowse is running, it watches for created, edited, moved, and deleted files. At the next start, it also reconciles changes made while the application was closed by comparing modification times and sizes. Routine use should not require scheduled rebuilds.

To rebuild or remove a root, right-click the tray icon, open “Indexed folders,” and expand the path:

  • Rebuild: scan that folder again. Use it after changing index rules or when the results are clearly out of sync with the drive.
  • Remove: unregister the folder and remove its entries from the search index. It does not delete the original files.
  • Add folder…: add another root to the same index.

You can hide the window while indexing or OCR is in progress. The tray tooltip and the progress view shown when you reopen Dowse reflect the current state.

OCR and privacy

Dowse uses the Windows Windows.Media.Ocr engine for text inside PNG, JPG, WebP, and BMP images. Recognition happens locally; images are not sent to a cloud service. The Simplified Chinese Windows language pack also handles common mixed Chinese and English screenshots.

Scanned PDFs are different. Dowse extracts an existing PDF text layer, but it does not currently run OCR over every page of an image-only scanned PDF. Use a PDF tool to add a searchable text layer first.

File parsing, indexing, queries, and recent-search history stay on the device. The index and configuration live under %LOCALAPPDATA%\dowse\data. Because the index contains extracted text, protect it as you would the source files. Dowse has no telemetry and does not upload queries. See the full privacy policy.

Troubleshooting

The hotkey does not show the window

Check the system tray for the Dowse icon and click it to show the window. If another application owns the shortcut, right-click the icon, open “Settings…,” and choose another combination. You can also use “Show Dowse” from the tray menu.

A file exists, but Dowse cannot find it

First check that it is under a path listed in “Indexed folders.” Then review its extension, excluded parent folders, and the maximum file-size rule. Image text will not appear until the OCR pass reaches that file. Rebuild the root after changing rules. Legacy .doc, .xls, and .ppt files and encrypted or password-protected documents do not currently have their contents extracted.

The name is searchable, but the PDF or Office text is not

A PDF needs an existing text layer; image-only scanned pages are not automatically OCRed. Office content extraction supports DOCX, XLSX, and PPTX. Damaged, encrypted, or password-protected files are skipped. Open the file in its normal application first to confirm that the text is readable.

An edited or deleted file still appears

Leave Dowse running in the tray so its file watcher can apply changes. If a sync tool replaced many files in an unusual way, restart Dowse to run reconciliation. Rebuild that indexed root if the result remains stale.

Does Dowse require administrator rights?

No. Normal indexing, file watching, OCR, and search work as a standard user. Administrator access is only an optional condition for the faster NTFS path.

How much disk space does the index use?

The index stores searchable text, so its size depends on the number and contents of your documents. Remove roots you rarely search, exclude build output, and use a reasonable file-size limit if the scope becomes too broad.

Report a problem or suggest an improvement

Right-click the tray icon and open “Help & Feedback” to return to this guide or open the issue page. You can also report a bug or request a feature on GitHub directly.

For a useful bug report, include the Dowse version, Windows version, steps to reproduce, and what you expected versus what happened. Crash and indexing diagnostics are in %LOCALAPPDATA%\dowse\data\logs\dowse.log. Check the file for local paths you do not want to publish before attaching it.
