使用 Dowse 搜索本地文件

这份指南面向 Windows 桌面版。你不需要了解搜索引擎：选好文件夹，等第一次索引完成，之后按快捷键输入你记得的文件名或正文即可。

适用于当前发布版 · 界面语言：中文 / English

安装与第一次索引

  1. 安装 Dowse。从 GitHub Releases 下载名称以 setup.exe 结尾的安装包。当前安装包没有代码签名；如果 SmartScreen 拦截，确认文件来自本项目发布页后，点“更多信息”再点“仍要运行”。
  2. 呼出搜索窗口。启动后，Dowse 会常驻系统托盘。按 Alt+`（数字 1 左边的反引号键）打开窗口；也可以左键点托盘图标。
  3. 选择第一个文件夹。第一次打开时，点“选择目录并建索引”，选择一个经常需要搜索的位置，例如“文档”或工作资料目录。Dowse 只会搜索你主动加入的文件夹。
  4. 等文字索引完成。窗口会显示当前处理数量和文件名。文字阶段完成后就可以搜索；图片较多时，OCR 会继续在后台处理，底部进度条会显示剩余进度。

建议从小范围开始。先加入真正存放资料的文件夹，而不是整个系统盘。结果更干净，第一次索引也更快。以后可在托盘菜单的“索引文件夹”中继续添加。

添加更多文件夹

右键单击托盘图标，打开“索引文件夹” → “添加文件夹…”。新增目录会并入现有索引，不会替换已经加入的目录。菜单会在每个索引目录后显示当前文档数。

日常搜索和结果操作

按 Alt+` 呼出 Dowse 后直接输入。你可以输入文件名的一部分，也可以输入 PDF、Office 文档、代码或文本文件中的词句。多个词默认要求同时出现；如果记得原句，用双引号包起来会更准确。

结果左侧显示文件名、路径和命中片段，右侧是预览。拖动中间分隔线可以调整两边宽度。搜索超过 50 条时，结果标题右侧会出现页码；在本页最后一条继续按 ↓，也会自动进入下一页。

筛选和排序

搜索框右侧有“全部类型”和“相关性”两个轻量菜单。类型可切换为文档、代码或图片；排序可选相关性、最新优先、最旧优先或最大优先。非默认选择会保留在界面上，方便确认当前条件。

打开、定位和复制

  • 双击结果或选中后按 Enter：用系统默认程序打开文件。
  • 按 Ctrl+Enter：在文件资源管理器中定位文件。
  • 按 Ctrl+C：复制完整路径。
  • 右键结果：可打开文件、定位所在文件夹、复制路径或只复制文件名。

窗口右上角的图钉会让 Dowse 在失去焦点后继续留在桌面上，适合一边查资料一边整理。固定状态只对本次运行有效。

最近搜索

清空搜索框后，Dowse 会列出最近 10 条搜索记录。用方向键选择，按 Enter 再次搜索；按 Delete 删除当前一条。记录只保存在本机。

搜索语法

大多数时候直接输入几个词就够了。需要缩小范围时，可以把下面的写法放在同一条查询里。

写法作用示例
空格多个条件同时满足（AND）季度 预算
双引号匹配完整短语"release checklist"
path:按文件名或所在路径缩小范围；有空格时加引号预算 path:报告
path:"My Docs"
ext:只看某种扩展名部署 ext:md
mtime:按修改日期过滤，支持 >、>=、<、<=合同 mtime:>=2026-01
size:按文件大小过滤；单位支持 B、KB、MB、GB日志 size:>10mb
-词 或 NOT 词排除包含该词的结果方案 -废弃
OR匹配两组条件中的任意一组；必须大写报价 OR 预算

mtime: 可写 YYYY-MM-DD 或 YYYY-MM。同一组内的条件先按 AND 组合，再用大写 OR 分组。例如 path:客户 合同 OR path:内部 模板。

设置与索引规则

点击窗口右上角的小齿轮、按 Ctrl+,，或右键托盘图标选择“设置…”，都能打开设置面板。

通用

  • 呼出快捷键：点“改键”后按下新组合，再确认。组合必须包含 Ctrl、Alt、Shift 或 Win 中至少一个修饰键。如果被别的软件占用，Dowse 会保留旧快捷键。
  • 透明效果：可以完整关闭；开启后可在低、中、高三档之间调整透明度。
  • 开机自启：控制登录 Windows 后是否自动启动 Dowse。
  • 界面语言：可跟随系统，也可固定为中文或 English。更改语言后需要重启应用。

索引规则

  • 排除目录：填写不需要索引的目录名，以逗号或换行分隔。默认排除 node_modules、target、.git、.venv 和 __pycache__；所有以点开头的目录始终排除。
  • 追加文本扩展名：用于项目自己的纯文本格式，例如 rst, adoc。这里是追加内建列表，不会覆盖它；扩展名不必带点。
  • 单文件体积上限：默认 20 MB。超过上限的文件会跳过，避免异常大的文件拖慢索引。

规则保存后，新发生的文件变更会使用新规则；要让已有索引完全一致，请重建索引。只有一个索引目录时，可以在面板里“立即重建”。有多个目录时，请从托盘菜单逐个重建。

维护索引文件夹

Dowse 运行时会监听文件新增、修改、移动和删除；下次启动时也会根据修改时间和文件大小补上关机期间的变化。正常使用不需要定期手动重建。

需要重建或移除目录时，右键托盘图标，进入“索引文件夹”，再展开对应路径：

  • 重建：重新扫描该目录。适合调整索引规则后使用，或在结果明显与磁盘内容不一致时排查。
  • 移除：取消这个目录并从搜索索引中删除其记录，不会删除磁盘上的原文件。
  • 添加文件夹…：把另一个目录加入同一份索引。

索引或 OCR 进行时仍可隐藏窗口。托盘图标的提示文字和再次打开后的进度会反映当前状态。

OCR 与隐私

Dowse 使用 Windows 自带的 Windows.Media.Ocr 识别 PNG、JPG、WebP 和 BMP 图片中的文字。识别在本机完成，图片不会发送给云端。中文系统的简体中文语言包也可处理常见的中英文混排截图。

扫描版 PDF 是一个例外。Dowse 会读取 PDF 自带的文字层，但当前不会逐页 OCR 只有图片、没有文字层的扫描 PDF。需要搜索这类资料时，请先用其他工具给 PDF 添加可搜索文字层。

文件解析、索引、搜索和最近搜索记录都留在本机。索引和配置位于 %LOCALAPPDATA%\dowse\data；索引包含从文件中提取的正文，应像原文件一样受到保护。Dowse 不包含遥测，也不会上传搜索词。完整说明见隐私政策。

常见问题

按快捷键没有出现窗口

先查看系统托盘里是否有 Dowse 图标；单击图标可以直接显示窗口。如果另一个应用占用了快捷键，右键托盘图标打开“设置…”，换一个组合。窗口可能已经固定在别的屏幕上，也可以先从托盘选择“显示 Dowse”。

明明有这个文件，为什么搜不到？

先确认文件位于托盘“索引文件夹”列出的路径下。再检查扩展名、排除目录和单文件体积上限；图片还要等 OCR 阶段完成。刚改过索引规则时，请重建对应目录。旧式 .doc、.xls、.ppt 以及加密或密码保护的文档目前不会抽取正文。

能搜到文件名，但搜不到 PDF 或 Office 正文

PDF 必须带文字层；图片扫描 PDF 不会自动 OCR。Office 正文支持 DOCX、XLSX 和 PPTX。损坏、加密或密码保护的文件会被跳过。可以先用原应用打开文件，确认正文可正常读取。

修改或删除文件后，结果没有马上变化

保持 Dowse 在托盘中运行，文件监听会增量更新。若文件由特殊同步工具批量替换，重启 Dowse 会进行一次对账；仍不一致时，从托盘重建该索引目录。

必须以管理员身份运行吗？

不必。普通索引、文件监听、OCR 和搜索都可在标准用户权限下工作。管理员权限只用于条件允许时启用更快的 NTFS 路径。

索引会不会占用很多空间？

索引保存了可搜索文本，大小取决于目录中文档的数量与内容。若范围太大，可移除不常搜索的根目录、排除构建产物，并合理设置单文件体积上限。

报告问题或提出建议

右键托盘图标，打开“帮助与反馈”，可以回到本指南或前往问题反馈页。也可以直接在 GitHub 上报告问题或提出建议。

报告问题时，请写明 Dowse 版本、Windows 版本、复现步骤，以及预期和实际结果。崩溃或索引异常时，日志位于 %LOCALAPPDATA%\dowse\data\logs\dowse.log；上传前请检查其中是否含有不希望公开的本地路径。
